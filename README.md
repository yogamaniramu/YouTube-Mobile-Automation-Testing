**YouTube Mobile Application Automation Testing**

**Project Description**:
Automated testing of  the YouTube Android application using Python and Appium.

**Tools and Technologies**:
-Python
-Appium
-Android Studio Emulator
-PyCharm
-Appium Inspector
-selenium
-Page Object Model(POM)

**Test Scenarios**:
1.Launch YouTube application.
2.Verify the YouTube home screen.
3.Click the Search button.
4.Enter "Python" in the search field.
5.Verify search results.
6.Select a video.
7.Verify video playback.
8.Pause and resume the video.
9.Navigate back to search results.
10.close the video.
11.click another video.

**Test Environment**:
1.Platform: Android
2.Device: Android Studio Emulator
3.Automation: Appium with UiAutomator2
4.Application: YouTube for Android

**FrameWork**:
Page Object Model(POM)

**Test Reports**:
HTML test report generated using pytest-html

**Screenshot**:
Screenshots are captured when a test fails.

**Project Status**:
Completed-Practice Automation Project
